Practical 1 – Sorting Algorithms
Aim
To study and understand different sorting algorithms used to arrange data in a specific order.

Introduction
Sorting is the process of arranging data in a particular order. Usually, data is arranged in ascending order or descending order.

For example:

Unsorted data:

45, 12, 78, 23, 9, 34

Ascending order:

9, 12, 23, 34, 45, 78

Descending order:

78, 45, 34, 23, 12, 9

Types of Sorting Algorithms
Some commonly used sorting algorithms are:

Bubble Sort – Compares adjacent elements and swaps them when they are in the wrong order.

Selection Sort – Finds the smallest or largest element and places it in its correct position.

Insertion Sort – Takes elements one by one and inserts them into their correct position.

Merge Sort – Divides the data into smaller parts, sorts them, and then combines them.

Quick Sort – Selects a pivot element and divides the data around the pivot.

Example
Consider the following numbers:

5, 3, 8, 1, 2

After sorting in ascending order:

1, 2, 3, 5, 8

Applications
Sorting algorithms are used in:

Searching data efficiently

Arranging student marks

Organizing names alphabetically

Arranging products by price

Managing databases

Ranking and result systems
