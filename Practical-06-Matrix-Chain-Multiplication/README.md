# Practical-06: Matrix Chain Multiplication

## Aim

To implement the **Matrix Chain Multiplication** problem using **Dynamic
Programming** and determine the minimum number of scalar multiplications
required to multiply a sequence of matrices.

---

## Objective

- To understand the Matrix Chain Multiplication problem.
- To understand the use of Dynamic Programming.
- To find the optimal order of matrix multiplication.
- To minimize the total number of scalar multiplications.
- To analyze the time and space complexity of the algorithm.

---
