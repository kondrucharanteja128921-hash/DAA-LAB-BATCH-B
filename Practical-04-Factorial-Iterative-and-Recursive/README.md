# Practical-04: Factorial - Iterative and Recursive

## Aim

To implement a program to find the factorial of a given number using both
**Iterative** and **Recursive** methods and compare their approaches.

---

## Objective

- To understand factorial calculation.
- To implement factorial using iteration.
- To implement factorial using recursion.
- To compare iterative and recursive approaches.
- To analyze the time and space complexity of both methods.

---

## Theory

The **factorial** of a non-negative integer `n` is the product of all positive
integers from `1` to `n`.

It is represented as:

```text
n! = n × (n-1) × (n-2) × ... × 2 × 1
